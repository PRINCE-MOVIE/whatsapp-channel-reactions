WhatsApp Channel Reactions

Affichez des réactions sous chaque message de votre chaîne WhatsApp — configuration rapide, interface moderne, et analytics basiques.

Connectez votre chaîne. Montrez les réactions.

Lorsque vous envoyez un message sur votre chaîne WhatsApp, il apparaît automatiquement sur ce site et les visiteurs peuvent réagir (👍 ❤️ 😂 🔥). Les réactions sont stockées ici et augmentent en temps réel.

Comment connecter

  1. Déployer le backend sur Render (folder api/).
  2. Déployer le frontend sur Vercel (folder frontend/).
  3. Dans le dashboard Meta, configurer le webhook vers https://YOUR_BACKEND_URL/webhook et mettre le même VERIFY_TOKEN.
  4. Envoyer un message sur votre numéro WhatsApp : il s'affichera automatiquement sur le site.

Fonctionnalités

  • Feed en temps quasi-réel (polling ou WebSockets possible)
  • Réactions par message (likers anonymes ou par utilisateur)
  • Envoi d'un récapitulatif au contact (optionnel)
  • Logs et modération basique

Besoin d'aide ?

Je peux : configurer Render/Vercel pour toi, ajouter un DNS personnalisé, ou activer l'authentification pour limiter les votes.
